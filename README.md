# MealMate - Team Project Frontend





## 🚀 Quick Start Guide (For Teammates)

If you just cloned this repository, follow these **3 simple steps** to set up your local workspace:

### 1. Install Dependencies
Restore the project development environment and download Tailwind CSS by running:
```bash
npm install
```

### 2. Start the Tailwind Compiler
Run the shortcut script to start the automatic CSS compiler. This will watch your HTML and CSS changes and build the layout engine in real-time:
```bash
npm run dev
```
*Keep this terminal tab running while you code!*

### 3. Launch the Project
Because the project uses JavaScript to dynamically load the layout components, you **cannot** open the `index.html` file directly from your file explorer. 
* Open the project in **VS Code**.
* Click the **Go Live** button in the bottom right corner (requires the *Live Server* extension).
